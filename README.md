- [x] صفحه لایسنس آنلاین (اولین صفحه بعد از اجرا)
- [x] صفحه ورود (Login) — User ID، Password، Registration، Visitor Mode، Admin Mode
- [x] ثبت کاربر جدید (Create New User)
- [x] داشبورد کاربر + سایدبار Function Form
- [x] Start Body Inspection (فرم اندازه‌گیری + START/SAVE/PRINT)
- [x] دیالوگ اتصال بلوتوث (اسکلت آماده، اسکن واقعی بعد از رسیدن سخت‌افزار)
- [x] پنجره نتایج/گزارش + چاپ (مطابق طرح چاپی اصلی)
- [x] Statistic Analysis (نمودار روند + تاریخچه)
- [x] پرسشنامه (۶ سوال، با همان محدودیت‌های تک/چندگزینه‌ای)
- [x] Admin Mode + User Administration (جستجو، حذف کاربر/داده/پرسشنامه، پاک‌کردن رمز)
- [x] System Management (خروجی/ورودی/حذف سوابق، حذف پرسشنامه)
- [x] لایه داده محلی آفلاین (SQLite در AppData) — هیچ داده‌ای جز چک لایسنس آنلاین ارسال نمی‌شود
- [x] فونت اختصاصی IRANSansXFaNum جاسازی‌شده در برنامه
- [ ] یکپارچه‌سازی واقعی با دستگاه آنالایزر (بلوتوث + قفل سخت‌افزاری) — منتظر در دسترس بودن سخت‌افزار

## گرفتن فایل exe بدون نصب هیچ برنامه‌ای (کامپایل آنلاین رایگان)

پروژه یک GitHub Actions workflow آماده داره (`.github/workflows/build.yml`) که کامپایل رو روی سرورهای گیت‌هاب (روی یک ماشین ویندوزی واقعی) انجام می‌ده و فایل exe رو براتون آماده می‌کنه — فقط با مرورگر، بدون نصب چیزی روی سیستم خودتون:

۱. یک حساب رایگان گیت‌هاب بسازید: https://github.com/signup
۲. یک ریپازیتوری جدید و خالی بسازید (دکمه‌ی سبز "New")
۳. توی صفحه‌ی ریپازیتوری، از دکمه‌ی "Add file" > "Upload files" همه‌ی محتوای همین پوشه (BodyComposition) رو بکشید و رها کنید، بعد "Commit changes" بزنید
۴. برید به تب **Actions** بالای صفحه — به‌صورت خودکار شروع به build می‌کنه (حدود ۲-۳ دقیقه طول می‌کشه)
۵. وقتی تیک سبز خورد، روی همون build کلیک کنید، پایین صفحه بخش **Artifacts** یک فایل zip به اسم `HumanBodyCompositionMonitor-exe` هست — دانلودش کنید، توش فایل exe آماده‌ی اجراست

این روش کاملا رایگانه و نیازی به نصب Visual Studio یا هر چیز سنگینی روی سیستم شما نیست.

## نصب و اجرا (روش محلی، اختیاری)

پروژه WPF روی .NET Framework 4.8 است (برای سازگاری با ویندوز ۷/۱۰/۱۱)، پس فقط با **Visual Studio روی ویندوز** اجرا می‌شود:

۱. Visual Studio 2022 Community (رایگان) + workload ".NET desktop development"
۲. باز کردن `src/BodyComposition.sln`
۳. اولین بار NuGet packages خودکار دانلود می‌شوند (نیاز به اینترنت)
۴. F5

## نکات فنی مهم

- **لایسنس**: `Services/LicenseService.cs` به یک آدرس placeholder وصل می‌شود (`https://license.yourdomain.com/api/v1`). وقتی بک‌اند لایسنس واقعی آماده شد، فقط همین آدرس را عوض کنید.
- **فرمول‌های ترکیب بدن**: `Services/BodyMetricsCalculator.cs` از فرمول‌های استاندارد BIA به عنوان شروع استفاده می‌کند، چون دستگاه فیزیکی هنوز متصل نیست. وقتی دستگاه رسید، فقط لازم است payload بلوتوث واقعی را پارس کرده و مستقیم یک `BodyMetrics` بسازید — بقیه برنامه (ذخیره‌سازی، گزارش، نمودار) بدون تغییر کار می‌کند.
- **کنتراست رنگ‌ها**: تمام دکمه‌ها و نوارهای رنگی برای خوانایی متن سفید روی رنگ‌های تیره (سبز تیره/آبی تیره/قرمز تیره و…) تنظیم شده‌اند.
